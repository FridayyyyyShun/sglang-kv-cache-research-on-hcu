# M1 匹配、分裂与原路径保持

1. 清空L1/L2，A长度8P+1，冷请求要求0命中，重复要求8P设备命中。
2. 发送无关前缀，逐rank确认A的查询页只留在L2。
3. B与A共享5P+P/2，再分叉。要求命中5P且host>0。
4. 树快照必须在累计5P处有至少两支；不是只检查某个node的局部key长度。
5. 重发A仍命中8P。
6. storage配置下：等待写回排空，flush本地树；新C在同一部分页分叉，要求storage命中5P；恢复A后再次检查同一分裂点。

证据：A/B/C响应的details；L2独有状态快照；分叉前后节点key/parent/children；insert、init_load_back、storage prefetch完成事件。所有rank逐个验证。没有自然压出L2独有状态记NOT_EXERCISED。
